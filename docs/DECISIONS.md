## 2026-09-03 — 로컬 DB는 Docker로, 비밀번호는 .env로 분리

- **무엇을 정했나**: MySQL은 로컬 설치 대신 docker-compose로 띄운다. compose 파일의 비밀번호는 `.env`(git 제외)로 빼고, 값이 비어 있는 `.env.example`만 커밋한다.
- **후보**: (DB) Docker 컨테이너 / 로컬 직접 설치 / H2 인메모리. (비밀번호) compose에 그대로 적어 커밋 / .env + .env.example 분리.
- **왜 이걸 골랐나**: Docker는 켜고 끄고 지우기가 한 줄이고, P4 컨테이너화와 그대로 이어진다. 비밀번호는 "로컬 개발용이라 당장 위험은 없지만, 비밀값은 git에 안 올리는 게 기본"이라 처음부터 습관을 들이기로 함.
- **버린 것의 대가**: H2였으면 설정 없이 바로 시작 가능했지만 나중에 MySQL 전환 작업이 한 번 더 생김. .env 분리는 새 PC에서 받을 때 `.env`를 손으로 만들어야 하는 수고가 생김.
